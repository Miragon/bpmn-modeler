Offers to declare an unknown process variable referenced in an inline BPMN script. When the caret sits on a variable the diagram model doesn't know, this appends a name-only entry to the diagram's *.bpmn.vars.json manifest and opens it so you can fill in the type and description. The variable then appears in script completion as an authored entry.

Available only in the modeler's inline Groovy script tabs, on a reference that doesn't resolve to a known process variable or Camunda binding.
