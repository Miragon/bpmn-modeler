# Learn the basics

Modeling in the canvas works the same way as in the Camunda Modeler:

- **Add elements** — hover an element and drag one of the blue icons, or
  click the canvas and pick a shape from the palette on the left.
- **Connect elements** — hover a shape and drag the arrow icon onto the next
  shape to draw a sequence flow.
- **Edit properties** — select any element and use the **Properties panel** on
  the right to set its name, type, and Camunda 7 / Camunda 8 attributes.

Everything you draw is saved straight back into the underlying `.bpmn` /
`.dmn` XML, so the file stays diff-friendly and reviewable in Git.
