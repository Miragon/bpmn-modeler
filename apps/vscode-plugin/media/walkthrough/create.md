# Create your first diagram

The BPMN Modeler opens automatically whenever you open a file with a
supported extension:

- **`.bpmn`** — a BPMN 2.0 process diagram
- **`.dmn`** — a DMN decision table

To start from scratch, create a new file and save it with one of those
extensions. VS Code then opens it directly in the graphical modeler instead
of the plain text editor.

> **Tip:** You can flip between the diagram and its raw XML at any time with
> **BPMN Modeler: Toggle Standard Text Editor** (`Ctrl+Shift+E`).
